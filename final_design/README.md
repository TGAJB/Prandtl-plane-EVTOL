# `final_design/` — run everything here

This is the single, clearly-marked place to **run the optimiser and produce every
final result**: all department characteristics, all graphs, and the complete
parameter list. Everything lands in [`results/`](results/).

## How to run

```bash
# from the project root
python final_design/run_design.py                 # run the optimiser, then regenerate ALL outputs
python final_design/run_design.py --skip-optimise # reuse the current design (fast — graphs/numbers only)
python final_design/run_design.py --clear-json    # forget the optimised design, regenerate the BASELINE
```

The default run executes the NSGA-II optimiser (Phase 1 acceptance check; Phase 2
search if rejected), which can take **minutes**. For a quick refresh of the
outputs without re-optimising, use `--skip-optimise`.

## Where the results are

```
final_design/results/
├── report.md                  # human-readable summary of all characteristics
├── run_log.txt                # full console log of the generation run
├── data/
│   ├── characteristics.json   # all headline numbers (mass, stability, c.g., ...)
│   └── parameters_full.{txt,json}   # THE COMPLETE PARAMETER LIST (override-aware)
└── figures/                   # EVERY graph, consolidated in one folder
```

`figures/` is where **final graphs are taken from**. It contains the figures
regenerated by each department plus the existing Sobol/Tornado sensitivity
heatmaps (copied in as standalone artifacts — these are **not** recomputed here).

## How the chosen design is applied (no parameters.py rewrite)

The optimiser **no longer edits `parameters.py`**. Instead `run_design.py` writes
the chosen design to **`final_design/chosen_design.json`**, and `parameters.py`
reads that file once at import (the `_ov(...)` override hook) and overrides the 7
design roots *before* deriving anything from them. Every module that imports
`parameters` then sees a fully consistent, tuned sheet.

It is **reversible and non-destructive**:

* Delete `final_design/chosen_design.json` (or run `--clear-json`) → the baseline
  literals in `parameters.py` are used unchanged.
* The JSON keys are exactly the optimiser's design variables:
  `design_point`, `x_LEMAC_fw`, `z_w_fw`, `b_vert_tail`, `s_aft_to_s_total`,
  `x_batt_cruise`, `x_batt_vtol`.

Because the override is read at **import time**, the consolidated outputs are
generated in a **fresh subprocess** (`generate_outputs.py`) launched after the
JSON is written — that guarantees every department module picks up the design
(a re-import inside the already-running optimiser process would not).

## Files

| file | role |
|---|---|
| `run_design.py` | entry point: run optimiser → write `chosen_design.json` → launch generator |
| `generate_outputs.py` | fresh-interpreter generator: collects characteristics, runs department plots, dumps parameters, writes the report |
| `dump_parameters.py` | serialises the whole parameter sheet (dataclasses + module globals) |
| `figure_capture.py` | forces the `Agg` backend and saves any `plt.show()` figures into `results/figures/` (department scripts are not edited) |
| `chosen_design.json` | the active design override (generated; git-ignored) |
| `results/` | all outputs (generated; git-ignored except `.gitkeep`) |
